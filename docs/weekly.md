# 每週挑選新工具

這個 repo 想長期做的事：每週從 crawler 的 Trending 快照挑出新上榜的 repo，挑有興趣的做成一個小成果，加到同一個 repo。腳本只負責挑候選，決定與實踐都由人完成，不會自動發布。

## 用法

```sh
python3 scripts/weekly_candidates.py            # 連網查授權、封存與最近推送時間
python3 scripts/weekly_candidates.py --offline  # 不連網，授權等標示為「未查證」
```

候選的定義：最新快照的週榜或月榜中，先前任何一份快照都沒出現過、且尚未實踐的 repo。只有一份快照時沒有比較基準，所以不會硬說哪個是新的。

## 每週流程（人來決定）

1. 更新資料：用 crawler 最新快照擴充 data/index.json（目前只含四個日期；擴充流程見 scripts/export_snapshots.py）。
2. 執行上面的腳本，讀候選清單。
3. 對有興趣的 repo：讀官方 README、確認授權與安裝需求、判斷是否能在隔離環境安全實踐。
4. 實踐成一個小成果，附教學、限制與測試；第三方授權補進 NOTICE.md。
5. 跑完整測試、掃描主機路徑與機密，再 commit 與推送。

## 為什麼不做自動排程

自動排程會在無人檢視時安裝與執行別人的程式，也可能自動推送。這兩件事的風險都高於省下的力氣，所以刻意讓每週只有「挑候選」自動化。

## 實測限制

- 候選只依榜單出現紀錄判斷，不代表品質、維護狀況或適合實踐。
- 授權等欄位來自 GitHub 公開 API；連線失敗時標示「未查證」。
- 已實踐清單寫在腳本的 BUILT 集合，新增成果時要同步更新。
