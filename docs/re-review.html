保留的警告與限制

  • HyperFrames 保留七項場景拆分／track 結構建議。runtime、layout、contrast 通過；motion audit 沒有啟用。
  • Impeccable 僅掃描探索器時保留暖紙色 warning，exit code 2；掃描整個 web 目錄另包含兩份生成教學的字級 warning。沒有宣稱 detector 全綠，也沒有為了通過掃描改掉既定配色。
  • CAD 是示範模型與工程圖，尚未切片、列印或測試線材保持力；任意尺寸組合不保證幾何有效。MCP 是一次一個請求的本機實驗，沒有啟用全域 hooks，也不是完整的通用 MCP host。
  • Chromium viewport 測試不等於使用者的本機瀏覽器、實體手機、SSH tunnel 或螢幕閱讀器測試。Worktree 檔案隔離不等於 credentials／網路隔離。

重跑驗收

從開發工作區根目錄執行：

.venv/bin/python -m pytest -q
PATH=".tools/node/bin:node_modules/.bin:$PATH" node_modules/.bin/playwright test
sh scripts/build_archify.sh
bash scripts/build_cad.sh
sh scripts/build_video.sh
.venv/bin/python context/mcp_experiment.py
bash scripts/worktree_demo.sh

瀏覽器測試會自己啟動 8765 server；若入口已在執行，先在啟動它的終端按 Ctrl+C。解壓成品包後，在解壓目錄啟動 python3 -m http.server 8767 --bind 127.0.0.1，再從原開發工作區執行 .tools/node/bin/node scripts/verify_portable.mjs http://127.0.0.1:8767/。此 verifier 使用開發環境的 Playwright，實際檢查目標是解壓成品，不需要在成品包安裝 Node 依賴才能瀏覽。
